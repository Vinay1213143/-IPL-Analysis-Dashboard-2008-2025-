# 🏏 IPL Analysis Dashboard (2008–2025)

## 📌 Project Overview

The **IPL Analysis Dashboard (2008–2025)** is an interactive Power BI project designed to analyze Indian Premier League (IPL) statistics, team performances, and player achievements across multiple seasons.

This dashboard provides meaningful insights into IPL matches, batting performances, team standings, and individual player statistics through interactive visualizations.

## 🎯 Project Objectives

- Analyze IPL statistics across seasons (2008–2025).
- Compare team performances and points table standings.
- Identify top-performing batsmen and bowlers.
- Track Orange Cap and Purple Cap holders.
- Analyze boundaries, centuries, and half-centuries.
- Provide season-wise insights using interactive filters.

## 📊 Dashboard Features

### 1. Key Performance Indicators (KPIs)
- Total Sixes
- Total Fours
- Total Matches
- Total Teams
- Total Centuries
- Total Half Centuries
- Total Venues

### 2. Player Performance Analysis
- Orange Cap Statistics
- Purple Cap Statistics
- Top 4's Hitters
- Top 6's Hitters

### 3. Team Performance Analysis
- IPL Points Table
- Matches Played
- Matches Won and Lost
- No Results and Ties
- Total Points

### 4. Interactive Filtering
- Season-wise filtering (2008–2025)
- Dynamic dashboard updates based on selected season.

## 🛠️ Tools & Technologies

- **Power BI Desktop** – Dashboard Development
- **Power Query** – Data Cleaning and Transformation
- **DAX** – Calculated Measures and KPIs
- **Data Visualization** – Interactive Charts, Cards and Tables

## 💡 Key Insights

The dashboard helps users understand:
- Team-wise performance across IPL seasons.
- Individual batting and bowling achievements.
- Seasonal trends in boundaries and scoring.
- Team standings and match outcomes.
- Overall IPL performance patterns.

## 🚀 How to Use

1. Clone or download this repository.
2. Install Microsoft Power BI Desktop.
3. Open the `.pbix` file.
4. Refresh the dataset if required.
5. Explore the dashboard using the Season slicer.
